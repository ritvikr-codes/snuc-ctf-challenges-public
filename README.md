# KINETICA CTF — Forensics & Steganography

A collection of **forensics and steganography challenges** created for
KINETICA CTF.

The challenges cover different techniques such as:

- Image Steganography
- Metadata Analysis
- File Forensics
- Network Forensics
- HTTP Forensics
- Memory Forensics
- Binary/File Analysis
