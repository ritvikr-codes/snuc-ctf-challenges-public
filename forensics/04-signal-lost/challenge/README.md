# Signal Lost

During the AX-07 blackout, the reconnaissance unit briefly re-established
communication with the KINETICA control network.

The connection lasted only a few seconds before disappearing again.

Investigators recovered a packet capture from the monitoring system.

Most of the traffic appears routine, but one communication doesn't belong.

Can you identify the hidden transmission and recover what was sent?

**File:** `kinetica_signal.pcap`

**Flag format:** `snuc{...}`
