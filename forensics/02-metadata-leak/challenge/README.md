# Ghost in the Metadata

**Category:** Digital Forensics  
**Difficulty:** Easy+  
**Points:** 150

AX-07 was operating normally when communication with the KINETICA
control system was interrupted.

Investigators recovered one image from the reconnaissance system.

Nothing unusual can be seen in the image itself.

However, digital artifacts often contain information that isn't visible
when the file is opened normally.

Can you recover what was left behind?

**File:** `kinetica_capture.jpg`

**Flag format:** `snuc{...}`
